A practical first contribution

Start small.
Leave it better.

  1. Try the browser demo to understand the intended interaction.
  2. Read the relevant repository’s README and development instructions.
  3. Choose a small issue or open a focused proposal with an expected outcome.
  4. Test the affected journey and document your hardware and results.
  5. Submit a pull request with the change, validation and remaining limits.

About hardware ports

Dragon Q6A is the reference development platform. A Raspberry Pi 5 image is planned. Other boards begin as community ports.

Desktop UI work can often start with component previews. A complete port also needs real-device graphics, input, audio, session and recovery testing.

Read each repository’s license. Upstream dependencies, fonts and branding retain their own terms.
